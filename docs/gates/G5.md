# Gate G5 · A family runs a week offline (DRAFT, awaiting 5.7)

**Status: drafted by the orchestrator on 2026-10-04. The gate opens when task 5.7 (accessibility pass) merges. Drew's family week has not happened yet; his pass or fail is queued in the decision queue when the gate opens.**

The plan's wording: a family with two child profiles uses Servo offline for a week and syncs cleanly; the parent view matches the run records.

## What the family does

1. Make the tester build and open it once online on each device (iPad and a laptop), so the service worker caches the app and the Rapier chunk:

   ```
   pnpm install
   pnpm release:dry
   pnpm release:preview
   ```

2. In the parent view (behind the parental gate on Home), make the adult account and two child profiles.
3. Turn the network off (airplane mode on the iPad; Wi-Fi off on the laptop). Keep it off for the week.
4. Each child builds and runs on their own profile on their own device, at least four sessions each. Both children also use the same device at least once, switching profiles.
5. At the end of the week, write down for each child: the builds saved, the challenges passed, the last breakdown fixed, and the card game rounds played.
6. Turn the network back on. Sync is disabled until a host exists (D10), so "syncs cleanly" at this gate means: both devices still hold every build and Run, and nothing was lost or duplicated when the app reloaded online. If a host has been chosen by then, reconnect both devices and check the conflict rule: the later save keeps the id and the other version becomes a kept copy (task 4.9's rule, task 5.5's fixtures).
7. Open the parent view's Progress for each child and compare with the notes from step 5, figure for figure.
8. Export one parts list and copy one share link; open the link on the other device.
