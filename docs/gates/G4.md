## What Drew does

1. Make the tester build on the laptop, from the repo root:

   ```
   pnpm install
   pnpm release:dry
   pnpm release:preview
   ```

   `release:preview` prints a local address. Open it on the iPad over the same Wi-Fi (Safari) and, for one child, on the laptop. An invite code is written by `release:dry` when `SERVO_INVITE_SEED` is set; see `packages/tools/src/release/README.md`.
2. Make a child profile from the parent view (behind the parental gate on Home), then hand the device over.
3. The adult may read any text aloud when asked, and nothing else. No pointing, no "try the red one".
4. Record one sheet per child (below). Stop a session at 25 minutes or when the child wants to stop.
