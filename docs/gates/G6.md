## What each family does

1. Opens the build once online on each device, makes the adult account and a profile per child.
2. Children build and run freely for two weeks. Adults may read text aloud and nothing else.
3. The adult runs the name-the-part card game with each child at the end of week two, from the parent view.
4. At the end, Drew reads the Section 14 measures from the parent view on each device, in a moderated session (events never leave the device, D109 and the data note).
