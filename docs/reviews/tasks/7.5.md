## Findings

- **F1 · moderate · `packages/app/src/store/index.ts:20-28`.** `ReadAloudScope`, `accessTheme` and `pageStorage` ride the store export. A separate `@servo/app/access` is the cleaner home (store = data; access = the options and their UI scope). It is not only a `package.json` exports change: the ESLint package-map rule allows parent to import only `@servo/app/store` (`packages/tools/test/lint-rules.test.ts:50,105` proves it) and CLAUDE.md's package map says the same, so the lint rule, its test and the map wording would all change. Default: accept for launch (the export is additive and the lint rule still holds); queue a follow-up to split it when Drew approves the rule change.
- **F2 · minor · shared-build page.** `mountSharedPage` takes no options, so a child's high contrast, dyslexia type, left hand and read-aloud do not reach the page a link opens (5.7 Q2). The done-when asks only for axe-green there, which holds. Default: queue a follow-up task in `packages/app`.
- **F3 · minor · `a11y-parent.test.tsx:151-154`.** The dyslexia check asserts the computed `fontFamily` contains OpenDyslexic, a string, not the face drawn. The face is a device font, so a machine without it falls back, and axe has no clipping rule. Default: add a scroll-width versus client-width check on the view's buttons with type on, or leave to the 5.7 checklist 8.2 (Drew's by-hand pass).
- **N1.** `watchFocus` starts after the press returns, so body focus that came and went inside the press is not seen. The layout-effect moves land in the same render, so none was found; a rest on body is caught.
- **N2.** The walk covers only the screens it opens (gate, accounts, rename, removal confirm, parts list, link field, card, closing line, refused save). A control shown only in an unwalked state, such as the gate after a wrong answer, would pass the enumeration. Default: add that state to the walk.
- **N3.** Left-handed on a page with no tray moves rows and lines to the right edge, as the builder said. Reasonable; Drew to judge by hand.
